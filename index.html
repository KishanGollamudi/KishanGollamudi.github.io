Cloud-Native GPU Inference & Edge LLM Serving

CUDA 13.0 K3s & Systems
Hardware-Accelerated Inference, Storage Decoupling & Bridge Networking

An end-to-end containerized LLM serving stack with full GPU offload on Linux. Decoupled runtime storage across physical block devices to prevent root filesystem exhaustion, bridged multi-namespace container-to-host networking via systemd overrides, and verified real-time CUDA compute allocation.

  • Storage Decoupling & Block Provisioning: Re-routed container daemon runtime (data-root) to a dedicated block partition with host-path volume binds, ensuring 0% root partition utilization during multi-GB image pulls and weight caching.
  • CUDA Acceleration & VRAM Optimization: Integrated NVIDIA driver stack (580.x, CUDA 13.0) with 100% parameter layer offload for Qwen2.5-Coder, maintaining compute occupancy at ~1.18 GiB / 4 GiB VRAM with zero host memory thrashing.
  • Multi-Interface Bridge Discovery: Implemented systemd service overrides (OLLAMA_HOST=0.0.0.0) with host-gateway DNS mapping, resolving bridge isolation constraints for seamless UI-to-daemon API proxying.

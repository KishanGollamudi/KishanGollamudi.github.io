Cloud TPU v5e LLM Serving Pipeline

Google Cloud TPU v5e OpenXLA & PyTorch
Hardware-Accelerated Systolic Array Inference, XLA Graph Compilation & Web UI Serving

An end-to-end cloud-native serving pipeline executing Qwen2.5-Coder-1.5B-Instruct on Google Cloud TPU v5e-1 accelerators with native PyTorch (torch.device("tpu")) and OpenXLA. Resolved XLA graph recompilation bottlenecks, eliminated causal decoder attention masking bugs via strict left-padding, and scaled batched throughput by 6x while exposing an interactive Gradio web serving interface.

  • Systolic Array Optimization: Deployed 1.5B parameter models in native bfloat16 onto TPU High Bandwidth Memory (HBM), driving warm inference from 26.84s down to 6.38s via cached computation graphs.
  • Causal Attention & Graph Stabilization: Diagnosed and resolved right-padding token corruption artifacts in autoregressive decoding by implementing left-side causal alignment (padding_side='left'), scaling batched throughput to 38.1 tok/s.
  • Interactive Serving & UI Integration: Built an integrated Gradio chat interface connected directly to the TPU execution context with dynamic token controls and public HTTPS reverse-tunnel ingress.
